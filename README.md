## What the paper tests

The project uses **two complementary but non-dynamically-coupled models** to compare physical AI with a functionally matched screen: (a) a 12-week synthetic outpatient monitoring microsimulation and (b) a finite-capacity psychiatric intake discrete-event simulation. Because the robot pathway also changes acceptance, alerting, reliability, and review work, model contrasts are **bundled-pathway comparisons**, not isolated causal effects of having a physical body. The proposed decision criterion requires both modeled patient benefit and acceptable retention, access, oversight and physical-safety burden; its empirical utility remains to be demonstrated.

## Installation and full reproduction

Python 3.11+ is recommended. The dependency versions are fixed in `requirements-lock.txt`.

```bash
python -m pip install -r requirements-lock.txt
python run_all.py
python -m pytest -q
```

`run_all.py` reruns patient/service primary simulations, original reanalyses, scenario stress tests, both audited parameter dictionaries, the high-resolution Sobol analysis, figures, manuscript and SHA-256 manifests, in that order. Because the global design evaluates 1,024 Saltelli base points for 12 patient and 11 service parameters with four workers and repeated stochastic evaluations, total reproduction time depends substantially on machine resources. Saved raw results allow checking estimates without rerunning.

Targeted commands:

```bash
make validate                # deterministic / structural checks
make sensitivity             # 1,024-base global Sobol design
make scenarios               # neutral and skeptical assumptions
make parameters              # complete parameter dictionaries and citation provenance
make figures                 # regenerate six main publication figures
make manuscript              # regenerate v4.5 DOCX files
make qa                      # run automated tests and model validation
```

The figure and layout generator reproduces the v4.4 numerical manuscript from the preserved v4.3 document and machine-readable results. `revise_narrative_v4_5.py` then applies traceable v4.5 editorial changes and appends eight externally verified references, maintaining the complete model specification and numerical tables. To reproduce the final manuscript using saved outputs, run `make manuscript`. The source v4.3 DOCX is retained for deterministic manuscript reconstruction; other historical drafts are available in the complete archival package.

## Interpretation of the new global sensitivity audit

The original small 128-point screening design showed material finite-sample inconsistencies (some S1>ST, and patient-completion ΣS1>1). The revised design increases the base size to **N=1,024** and synchronizes the synthetic patient cohort/latent event streams across A/B/cross-evaluations **within each Sobol design row**. A nested maximum-rate Poisson stream with matched thinning uniforms preserves service arrival CRN as demand varies. The first-order estimator uses Saltelli covariance; the total-order estimator uses Jansen squared differences; all S2 pairwise estimates and 350 design-row bootstrap intervals are retained.

This mitigates, but does **not eliminate**, finite-sample sensitivity-estimator instability. For patient response and service mean waiting, ΣS1≤1 and all first-order point estimates are ≤their respective total-order estimates. A few near-zero components of other endpoints still have S1>ST and must **not** be interpreted. Interactions are exploratory and are not corrected for multiple testing. All inputs are **independently uniform stress-test ranges**, not estimated posterior distributions; outer parameter and inner stochastic uncertainty are not clinical-sampling uncertainty.

## Reproducibility and availability

- Primary synthetic simulations are **fixed-assumption** paired replication experiments; per-replication cohorts/demand are shared within each experiment.
- Base-case, alternative endpoint and capacity modules use **independent label-derived random streams**, so estimates from nominally equal configurations may differ at ordinary Monte Carlo precision; see Supplementary Table S4.
- In the queue model, work is carried across successive 420-minute **productive working-day blocks**; overnight/calendar-time closures and explicit overtime shifts are not modeled. A daily excess-workload proxy must not be interpreted as measured clock-time overtime.
- Data and analysis files include executable seeds, scenario definitions, matrices, raw and adjusted tests, and SHA-256 manifests; no personal data are included.
- Physical injury, calibration, stakeholder elicitation, independent conceptual face validation, cost effectiveness, and real-world prediction are **out of scope** for the synthetic study.
