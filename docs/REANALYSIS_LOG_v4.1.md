# Reviewer reanalysis log v4.1

All analyses below preserve the v4.0 primary outputs. They are explicitly exploratory diagnostics motivated by scientific review and are generated by `reviewer_reanalysis.py`.

| ID | Analysis | Rationale | Main result | Interpretation |
|---|---|---|---|---|
| R1 | Attrition-estimand sensitivity | Completion differed materially between pathways, making LOCF consequential. | Robot minus screen response was +6.23 percentage points under LOCF, +5.53 under BOCF, and +10.21 among completers. | Direction was stable, but magnitude depended on the estimand. |
| R2 | Nested parameter scenarios | A single first-order simulation within each parameter draw mixed scenario and Monte Carlo variability. | With five inner replications per 250 draws, response favored the robot in 83.2%, completion favored the screen in 100%, and review burden was higher in 100%. | Qualitative conclusions were unchanged; proportions apply only to the selected ranges. |
| R3 | Service intake-capacity sensitivity | The base screen and robot pathways used different numbers of intake stations. | Increasing the human-gated pathway from two to five intake stations did not remove the roughly 36-minute mean-wait penalty. | Clinician-stage duration and review burden dominate this modeled configuration. |
| R4 | One-block pathway decomposition | The full robot-screen contrast changes multiple assumptions and cannot identify a pure embodiment effect. | The symptom embodiment increment improved response with negligible completion change; acceptance-friction assumptions reduced response and completion; oversight assumptions drove review and physical exposure. | The primary estimate is a bundled pathway contrast, not a causal embodiment effect. |
