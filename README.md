# Physical AI in Psychiatry

**Reimagining Psychiatric Care with Physical AI through Multiscale Modeling of Benefit Burden and Breakeven Conditions**

This repository accompanies a study of physical AI pathways in psychiatric care. It contains the manuscript, full mathematical and operational model specifications, simulation source code, input assumptions, generated datasets, statistical analyses, sensitivity matrices, and publication figures. The research examines patient-level longitudinal monitoring and psychiatric intake operations through two complementary computational models.

The central research question is whether embodied systems can deliver incremental patient benefit while meeting operational requirements for completion, clinician workload, accessibility, and safety. The models contrast usual/manual care, a functionally matched screen interface, an embodied robot, and a robot with human verification.

### Quick start

```bash
python -m pip install -r requirements-lock.txt
python -m pytest -q
python analysis/validate_models.py
make figures
```

`make figures` rebuilds the six publication figures from the saved numerical results. `make manuscript` updates the editable manuscript and Supplementary Information using the stored results. `make reproduce` runs the complete computational workflow, including the considerably more demanding global sensitivity analysis. The source datasets are already included, so reviewing the results does not require a full model rerun.

## Scientific interpretation

The individual model follows synthetic outpatient trajectories over 12 weeks. The service model represents finite-capacity intake over 35 observed working days following warm-up. Both models share pathway definitions; their simulations are executed independently and are **not dynamically coupled**.

The base-case human-gated robot pathway improves modeled response by **6.29 percentage points** and reduces modeled missed high-acuity intake cases by **10.85 percentage points**, while reducing 12-week completion by **5.42 points** and increasing mean clinic waiting time by **34.41 working minutes** relative to the screen. These values are conditional on the specified assumptions and should be interpreted together with the neutral/skeptical cases and global sensitivity results. See the manuscript and [results map](docs/RESULTS_TO_CODE.md) for uncertainty intervals, denominators, and code provenance.

All distributed patient-level records are generated by the computational model. No clinical records or personally identifying patient information are included. Parameter ranges are transparent stress-test assumptions; empirical calibration, independent predictive validation, and formal stakeholder face validation have not been completed. The resulting effect estimates characterize model behavior under the stated scenarios and do not constitute demonstrated clinical efficacy or deployment safety.
